    Catálogo de métodos¶

    Documentação completa de todos os métodos da ITMO_FS acessíveis pelo itmofs-lab, com o que entra e o que sai de cada um.

    Embedded (embedded)¶

    método status resumo
    MOS OK Minimizing Overlapping Selection (com/sem SMOTE) via modelo linear regularizado.

    Ensembles (baseados em medida) (ensembles.measure_based)¶

    método status resumo
    WeightBased OK Ensemble por fusão de SCORES normalizados de filtros base.

    Ensembles (baseados em modelo) (ensembles.model_based)¶

    método status resumo
    BestSum OK_WITH_ADAPTER Ensemble model-based: importâncias ponderadas por desempenho de CV (só treino).

    Ensembles (baseados em ranking) (ensembles.ranking_based)¶

    método status resumo
    Mixed OK Ensemble por fusão de RANKINGS (robusto à escala).

    Filtros multivariados (filters.multivariate)¶

    método status resumo
    CFR OK Maximiza correlação e minimiza redundância.
    CIFE OK Conditional Infomax Feature Extraction.
    CMIM OK Conditional Mutual Info Maximisation.
    DCSF OK Dynamic change of selected feature.
    DISRWithMassive OK Double Input Symmetric Relevance (kASSI); maximiza info mútua evitando densidade multivariada grande.
    FCBFDiscreteFilter OK Fast Correlation Based Filter para dados discretos (info mútua; remove redundância).
    ICAP OK Interaction Capping.
    IWFS OK Interaction Weight based feature scoring.
    JMI OK Informação mútua conjunta (complementaridade).
    MIFS OK Relevância menos penalização de redundância (parâmetro beta).
    MIM OK Maximiza relevância (informação mútua) com o alvo.
    MIMAGA BROKEN_IN_0_3_3 MIM + algoritmo genético (estocástico, custoso).
    MRI OK Max-Relevance and Max-Independence.
    MRMR OK Máxima relevância e mínima redundância.
    STIR OK Seleção via algoritmo STIR (baseado em vizinhança).
    TraceRatioFisher OK Trace Ratio supervisionado (versão Fisher, baseado em similaridade).
    generalizedCriteria OK Combinação linear de relevância/redundância/dependência (beta, gamma).

    Filtros esparsos (filters.sparse)¶

    método status resumo
    MCFS OK_WITH_ADAPTER Unsupervised FS for Multi-Cluster Data.
    NDFS OK_WITH_ADAPTER Nonnegative Discriminative Feature Selection.
    RFS OK_WITH_ADAPTER Robust Feature Selection (L2,1-norms).
    SPEC OK_WITH_ADAPTER Spectral Feature Selection.
    UDFS OK_WITH_ADAPTER Unsupervised Discriminative Feature Selection.

    Filtros univariados (filters.univariate)¶

    método status resumo
    VDM SUPPORT_ONLY Métrica de diferença de valores categóricos condicionada às classes.
    anova OK Estatística F de ANOVA por feature.
    chi2_measure OK Estatística qui-quadrado entre feature e classe.
    f_ratio_measure OK Calcula o Fisher score de cada feature (separação entre classes).
    fechner_corr OK Correlação de sinal (Fechner) de cada feature.
    fit_criterion_measure BROKEN_IN_0_3_3 Critério de ajuste por classe (centros/variâncias).
    gini_index OK Índice de Gini: medida de dispersão estatística por feature.
    information_gain OK Informação mútua I(X;Y)=H(X)-H(X
    kendall_corr OK Correlação de sinal (Kendall) de cada feature.
    laplacian_score OK Score laplaciano (não supervisionado); menor é melhor.
    pearson_corr OK Correlação de Pearson de cada feature com o alvo.
    qpfs_filter DEPENDENCY_MISSING Quadratic Programming Feature Selection.
    reliefF_measure OK Medida ReliefF baseada em vizinhos mais próximos.
    spearman_corr OK Correlação de Spearman de cada feature com o alvo.
    su_measure OK Correlação informacional SU(X,Y)=2*I(X;Y)/(H(X)+H(Y)).

    Filtros não supervisionados (filters.unsupervised)¶

    método status resumo
    TraceRatioLaplacian OK_WITH_ADAPTER Trace Ratio não supervisionado (Laplacian).

    Híbridos (hybrid)¶

    método status resumo
    FilterWrapperHybrid BROKEN_IN_0_3_3 Filtro rápido seguido de wrapper.
    Melif OK Otimiza pesos de um ensemble de filtros para maximizar um scorer (só treino).

    Wrappers (wrappers)¶

    método status resumo
    AddDelWrapper BROKEN_IN_0_3_3 Wrapper baseado em busca guiada por classificador.
    BackwardSelection OK Remove uma feature por vez até atingir n_features.
    HillClimbingWrapper BROKEN_IN_0_3_3 Wrapper baseado em busca guiada por classificador.
    RecursiveElimination BROKEN_IN_0_3_3 Wrapper baseado em busca guiada por classificador.
    SequentialForwardSelection OK Adiciona sequencialmente a feature que mais melhora o classificador.
    SimulatedAnnealing LEAKAGE_BY_DESIGN Wrapper baseado em busca guiada por classificador.
    TPhMGWO BROKEN_IN_0_3_3 Wrapper baseado em busca guiada por classificador.
    qpfs_wrapper DEPENDENCY_MISSING Quadratic Programming Feature Selection na forma de wrapper.
